# 🧠 คู่มือการเลือกและการตั้งค่า LLM ขนาดกะทัดรัด (~3B Parameters) สำหรับ Chatbot

เอกสารฉบับนี้จัดทำขึ้นเพื่ออธิบาย **ขั้นตอนการ Setup โปรเจกต์ตั้งแต่เริ่มต้น** และ **การวิเคราะห์เปรียบเทียบโมเดล LLM ขนาดกะทัดรัด (~3B Parameters)** ซึ่งเหมาะอย่างยิ่งสำหรับรันบนคอมพิวเตอร์ทั่วไป (Local Machine) โดยใช้ RAM/VRAM น้อยกว่า 2.5 GB แต่ยังคงให้คำตอบภาษาไทยและทำตามบริบท RAG ได้อย่างมีประสิทธิภาพสูง

---

## 🚀 1. คู่มือการ Setup โปรเจกต์ตั้งแต่ต้นจนจบ (Step-by-Step Setup Guide)

### 📌 สิ่งที่ต้องเตรียมก่อนเริ่มต้น (Prerequisites)
1. **Python**: เวอร์ชัน 3.10 ขึ้นไป (แนะนำ 3.10 – 3.13)
2. **Ollama**: ติดตั้งจาก [ollama.com](https://ollama.com/) และเปิดใช้งานอยู่
3. **Docker** *(เฉพาะเมื่อต้องการใช้งาน Neo4j Knowledge Graph)*

---

### ขั้นตอนที่ 1: เตรียม Virtual Environment และติดตั้ง Dependencies
เปิด PowerShell หรือ Terminal ในโฟลเดอร์โปรเจกต์ `chongpenyang`:

```powershell
# 1. สร้าง Virtual Environment (ถ้ายังไม่มี)
python -m venv venv

# 2. เปิดใช้งาน venv
.\venv\Scripts\Activate.ps1   # สำหรับ Windows PowerShell
# source venv/bin/activate    # สำหรับ macOS / Linux

# 3. ติดตั้ง Library ตามไฟล์ requirements.txt
pip install -r requirements.txt
```

---

### ขั้นตอนที่ 2: เตรียมโมเดล LLM ใน Ollama (ขนาด ~3B)
รันคำสั่งดาวน์โหลดโมเดล `qwen2.5:3b` ซึ่งมีขนาดเพียง **1.9 GB**:

```powershell
# ดาวน์โหลดโมเดล
ollama pull qwen2.5:3b

# ตรวจสอบว่าโมเดลพร้อมใช้งาน
ollama list
```

---

### ขั้นตอนที่ 3: ตั้งค่า Environment Variables (`.env`)
คัดลอกไฟล์เทมเพลตและกำหนดค่า:

```powershell
# คัดลอกไฟล์ .env.example มาเป็น .env
copy .env.example .env
```

ตรวจสอบค่าสำคัญในไฟล์ `.env`:
```ini
# Chatbot & LLM Settings
OLLAMA_MODEL=qwen2.5:3b
OLLAMA_BASE_URL=http://localhost:11434
PDF_PATH=documents.pdf
VECTOR_STORE_TYPE=chroma
CHROMA_PATH=chatbot/data/chroma_db
FAISS_PATH=chatbot/data/faiss_index
```

---

### ขั้นตอนที่ 4: สร้างดัชนี Vector Store (ChromaDB) และ BM25
รันสคริปต์เพื่อสกัดข้อความจาก `documents.pdf`, ตัดแบ่ง Chunks แบบ Parent-Child และบันทึกลงฐานข้อมูล:

```powershell
python -m chatbot.ingestion.build_index
```
*(เมื่อสำเร็จ จะพบโฟลเดอร์ `chatbot/data/chroma_db` และไฟล์แคช `documents_cache.pkl`)*

---

### ขั้นตอนที่ 5: ทดสอบการทำงานของระบบ

```powershell
# 1. รัน Unit Tests เพื่อตรวจความสมบูรณ์ของระบบ
pytest chatbot/tests

# 2. เปิดหน้าต่างแชท Interactive CLI เพื่อทดลองถาม-ตอบ
python -m chatbot.interfaces.app_chat

# 3. รันการประเมินผลเชิงปริมาณ (SBERT & BERTScore Benchmark)
python -m chatbot.evaluation.run_evaluation --quick

# 4. รัน Webhook Server (สำหรับ LINE Bot และ REST API)
python -m chatbot.interfaces.webhook
```
*(ทดสอบยิง API ผ่าน Browser ได้ที่: `http://localhost:5000/query?q=ขอสูตรกาแฟเอสเพรสโซ่`)*

## ⚖️ 2. ตารางวิเคราะห์เปรียบเทียบโมเดล 3 ตัวขนาด ~3B Parameters

ตารางเปรียบเทียบ 3 โมเดลคลาส **3B Parameters** ที่มีขนาดใกล้เคียงกัน แต่พัฒนาจาก 3 องค์กรชั้นนำ:

| หัวข้อการประเมิน | 1. Qwen 2.5 (3B-Instruct) 👑 | 2. Llama 3.2 (3B-Instruct) 🦙 | 3. Gemma 2 (2B-Instruct) 💎 |
| :--- | :--- | :--- | :--- |
| **ผู้พัฒนา (Organization)** | Alibaba Cloud | Meta AI | Google DeepMind |
| **ขนาดพารามิเตอร์** | **3.09B Parameters** | **3.21B Parameters** | **2.61B Parameters** |
| **ขนาดไฟล์บนดิสก์ (Q4_K_M)** | **~1.9 GB** | **~2.0 GB** | **~1.6 GB** (เบาที่สุด) |
| **Context Window สูงสุด** | 32k / 128k tokens | 128k tokens | 8k tokens |
| **การใช้ RAM/VRAM ขณะทำงาน** | ~2.2 – 2.6 GB | ~2.3 – 2.8 GB | **~1.8 – 2.2 GB** |
| **ความเข้าใจภาษาไทย (Thai Fluency)** | ⭐⭐⭐⭐⭐ (ยอดเยี่ยมที่สุด ไวยากรณ์เป็นธรรมชาติ) | ⭐⭐⭐ (ปานกลาง เข้าใจประโยคทั่วไปได้) | ⭐⭐⭐ (ปานกลาง เข้าใจคำศัพท์ทั่วไปได้) |
| **ความแม่นยำในการอ้างอิง RAG** | ⭐⭐⭐⭐⭐ (ปฏิบัติตามกฎ Zero-Hallucination ดีมาก) | ⭐⭐⭐⭐ (ทำตามคำสั่งดี แต่อาจมีคำตอบสั้นเกินไป) | ⭐⭐⭐⭐ (กลั่นกรองคำตอบได้ตรงประเด็น) |
| **ความเร็วในการประมวลผล (CPU)** | **เร็วมาก (~10–12 วินาที)** | **เร็วมาก (~10–12 วินาที)** | **เร็วที่สุด (~8–11 วินาที)** |
| **คำสั่งดึงโมเดลใน Ollama** | `ollama pull qwen2.5:3b` | `ollama pull llama3.2:3b` | `ollama pull gemma2:2b` |

## 🔍 3. เจาะลึกจุดเด่นและข้อจำกัดของแต่ละโมเดล

### 1) Qwen 2.5 (3B-Instruct) — *ตัวเลือกอันดับ 1 สำหรับ RAG ภาษาไทย (Recommended)*
- **จุดแข็ง**:
  - ได้รับการเทรนด้วยคลังข้อมูล Multilingual ขนาดใหญ่ ทำให้เข้าใจโครงสร้างประโยค วรรณยุกต์ และศัพท์เฉพาะทางภาษาไทยได้ดีที่สุดในกลุ่ม 3B
  - ขนาดกะทัดรัดเพียง 1.9 GB รันบน CPU โน้ตบุ๊กทั่วไปได้รวดเร็วมาก (Inference time ~11 วินาที)
  - ตอบคำถามโดยยึดตาม [บริบทเอกสาร] อย่างเคร่งครัด อ้างอิงเลขหน้าและหัวข้อได้อย่างถูกต้อง
- **ข้อจำกัด**:
  - เมื่อเปรียบเทียบกับรุ่น 7B คำอธิบายอาจจะกระชับกว่าเล็กน้อย แต่ความถูกต้องของตัวเลขและสูตรกาแฟเท่าเทียมกัน

---

### 2) Llama 3.2 (3B-Instruct) — *โมเดลขนาดเล็กมาตรฐานใหม่จาก Meta*
- **จุดแข็ง**:
  - โครงสร้างน้ำหนักเบา ออกแบบมาเพื่อรันบน Edge Device และ Mobile/Desktop
  - มีทักษะการสรุปใจความสำคัญ (Summarization) และการปฏิบัติตาม Format คำสั่งภาษาอังกฤษที่ดีมาก
- **ข้อจำกัดในงานภาษาไทย**:
  - ในการตอบคำถามภาษาไทยที่มีคำศัพท์ทางเทคนิคกาแฟ (เช่น การสกัด, อัตราส่วน, หรืออาการ Over-extraction) บางครั้งจะมีคำทับศัพท์ภาษาอังกฤษปะปน หรือตอบด้วยรูปประโยคสั้นเกินไป

---

### 3) Gemma 2 (2B-Instruct) — *โมเดลจิ๋วแต่แจ๋วที่กลั่นกรองความรู้จาก Google DeepMind*
- **จุดแข็ง**:
  - **Knowledge Distillation**: ใช้โมเดลยักษ์ใหญ่ขนาด 27B ของ Google มาทำ Distillation ถ่ายทอดความรู้ลงในสถาปัตยกรรม 2.6B ทำให้มีคะแนน Benchmark วิชาการสูงเกินตัว
  - **กินทรัพยากรน้อยที่สุด**: ขนาดไฟล์เพียง 1.6 GB ใช้ RAM ไม่ถึง 2 GB รันบนคอมพิวเตอร์ทั่วไปได้ลื่นไหลและเร็วที่สุด
  - **Safety & Structured Output**: ปฏิบัติตามคำสั่งจัดรูปแบบข้อความและหัวข้อได้เป็นระเบียบเรียบร้อย
- **ข้อจำกัดในงานภาษาไทย**:
  - คลังคำศัพท์เน้นภาษาอังกฤษเป็นหลัก หากเป็นประโยคภาษาไทยยาวๆ อาจมีการเว้นวรรคคำแปลกๆ หรือสะกดสระภาษาไทยบางตัวเพี้ยนเมื่อเทียบกับ Qwen
  - Context Window อยู่ที่ 8k tokens (น้อยกว่า Qwen และ Llama) แต่เพียงพอสำหรับการป้อนบริบท RAG ที่จำกัดงบประมาณ (~2k tokens)

## 🎯 4. สรุปผลการประเมินและการสลับใช้งาน

- สำหรับระบบ **SmartDoc Barista AI**: แนะนำให้ใช้ **`qwen2.5:3b`** เป็นค่า Default เพราะประหยัดทรัพยากรเครื่องลงกว่า 60% จากรุ่น 7B และตอบกลับได้เร็วกว่าเกือบ 2 เท่า โดยที่ยังคงความถูกต้องของสูตรกาแฟและการอ้างอิงเอกสารครบถ้วน
- หากต้องการสลับไปทดลองโมเดลอื่น เพียงแก้ไขบรรทัดเดียวใน `.env`:
  ```ini
  OLLAMA_MODEL=llama3.2:3b   # หรือ gemma2:2b
  ```
  แล้วเริ่มใช้งานได้ทันทีโดยไม่ต้องรันคำสั่งอื่นเพิ่มเติม
